Tentang Saya

Saya memulai perjalanan di dunia teknologi sejak duduk di bangku SMK dengan jurusan Rekayasa Perangkat Lunak, kemudian melanjutkan ke perguruan tinggi di bidang Teknik Informatika. Latar belakang akademis ini memperkuat fondasi saya dalam memahami konsep komputasi, logika pemrograman, serta pengembangan sistem yang adaptif.

Karier saya dimulai di industri konveksi, lalu berkembang di dunia garment. Setelah itu, saya mendalami bidang pemisahan warna untuk printing sablon, di mana saya menguasai software desain profesional.
Seiring waktu, saya kembali ke akar minat saya di dunia pemrograman, khususnya di pengembangan frontend dan backend.

Saya adalah pribadi yang menyukai tantangan baru, cepat beradaptasi, dan memiliki keinginan besar untuk terus tumbuh baik dalam hal teknis maupun dalam kolaborasi lintas bidang.
